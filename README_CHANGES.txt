راهنمای فایل‌های به‌روزشده کوگنی‌کد جهت آپلود در گیت‌هاب
=============================================================

این پوشه شامل تمام فایل‌هایی است که در جریان بهینه‌سازی و رفع باگ‌های برنامه تغییر یافته‌اند.
ساختار پوشه‌ها دقیقاً مطابق ساختار مخزن (Repository) اصلی گیت‌هاب مرتب شده است.

فایل‌های تغییر یافته و توضیحات:
-------------------------------------------------------------
1. syntax.js
   - بازنویسی کامل موتور تشخیص ۳۴ زبان برنامه‌نویسی (Syntax.detect)
   - رفع کامل تداخل بین زبان‌ها (از جمله تشخیص پاسکال، C در برابر C++، TS در برابر JS و...)
   - پیاده‌سازی سیستم امتیازدهی چندسطحی و لنگرهای قطعی ساختاری

2. checker.js
   - اصلاح بررسی کدهای Rust (عدم تداخل کاراکترهای تک‌کوتیشن مانند '(' با براکت‌های نبسته)
   - افزودن پشتیبانی از رشته‌های با کوتیشن تکی در زبان Ruby
   - بهبود و بهینه‌سازی بررسی ساختار JSON

3. app.js
   - بهبود اتصال تغییرات ویرایشگر با نوار وضعیت و برچسب زبان در گوشه پایین سمت راست
   - رفع باگ‌های لود و سنکرون رویدادها

4. index.html
   - بهینه‌سازی ساختار و ارتقای استانداردها بدون هیچ‌گونه دستکاری در ساختار ظاهری

5. .gitignore
   - تنظیم و تمیزکاری نادیده‌گرفتن فایل‌های موقت تستی و اسکرین‌شات‌ها

6. release-manifest.json
   - به‌روزرسانی هش‌های SHA-256 و متادیتاهای نسخه انتشار

7. .github/workflows/ios.yml
   - تصحیح پایپ‌لاین CI برای ساخت و اعتبارسنجی خودکار پروژه در GitHub Actions

8. native/CogniCode/App/WebView.swift
   - رفع پایداری بریج WKWebView در اپلیکیشن iOS

9. پوشه native/Web/ (شامل syntax.js, checker.js, app.js, index.html, sw.js)
   - نسخه همگام‌سازی شده وب‌اپ درون هسته نیتیو iOS

نحوه استفاده / آپلود در گیت‌هاب:
-------------------------------------------------------------
روش اول (آپلود مستقیم در وبسایت گیت‌هاب):
کافی است این فایل‌ها را در مسیر متناظر خود در ریپازیتوری GitHub بکشید و رها کنید (Drag & Drop) یا دکمه Upload files را بزنید.

روش دوم (کپی در پوشه لوکال ریپازیتوری):
محتویات این پوشه را دقیقاً روی پوشه ریپازیتوری خود Paste و Overwrite کنید و سپس دستورات git add، git commit و git push را اجرا فرمایید.
